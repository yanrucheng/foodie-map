# Local dining icons

Static paths live in `src/config/restaurantPresentation.ts` and are bundled with the application.
Extracted only graphics from the approved P09 `preview.html` (SHA-256
`368eb70a555d2e72b141ae4206ddcce417d5a338c03a8c455627279f72869d1f`).

- Tabler Outline 3.46.0: bowl-chopsticks, meat, fish, cake-roll, chef-hat, tools-kitchen-2. https://github.com/tabler/tabler-icons — `tabler-LICENSE.txt`.
- Lucide 1.46.0: cooking-pot. https://github.com/lucide-icons/lucide — `lucide-LICENSE.txt`.
- Multi-dish tray: original drawing from the approved P09 preview, maintained with this project.

No preview restaurant classifications are imported. Runtime data cannot override SVG paths.
